# 动态融合未改善：原因与受控优化

2026-11-02，仍为澳超已看过开发样本，非新的未见验证。

## 实测原因

旧门控在训练/校准/末段给constant专家平均80.62%/81.24%/80.67%权重，逐段几乎不变。它主要学到了常数模型，而不是明显的逐场专家切换。Poisson/DC具有相同均值和接近相同熵，多个专家高度相关；13项输入、52个softmax系数相对182场训练样本复杂，不能假定复杂模型有增益。

constant的训练Log Loss3.03492优于Poisson3.11986，校准2.89849优于2.92794，但末段3.17623反而弱于3.15287。这是实测的相对表现变化，不足以将所有误差归咎于过拟合。场均总球2.923/2.806/3.373提示时间分布变化；只能作为诊断线索，不是完整因果证明。

进一步逐场核对训练段：Poisson与DC的统计第一比分相同率98.35%，平均总变差距离0.00278；Poisson与ML相同率97.80%，平均总变差距离0.01621。增加这些高度相似的专家没有形成足够互补信息，不应把专家数量当信息量。

旧温度0.85656强化概率集中，末段损失从动态3.16141恶化至3.19437。严格正温度变换不改变矩阵排序，故不能靠温度本身提高比分Top1。Log Loss优化也不保证Top1改善；三种球队专家训练Top1均18/182，constant20/182，缺明显互补信号。

## 本轮优化

新增`runtime/v2_test/ensemble_guarded.py`：训练段拟合更简单的静态权重并向Poisson正则收缩；另保留75%基准锚定的动态候选。校准段只比较预先固定的温度0.95/1/1.05，并要求Top1不低于校准基准、Log Loss不超过基准+.02，再按Top1/Log Loss选择。Poisson始终为可回退候选。所有选择在末段评分前锁定；测试验证修改末段标签不改变参数和选择。

校准选中static、T=0.95，Poisson72.5905%、constant27.4095%，DC/ML接近零。末段Top1仍7/67，Log Loss3.15678；相较旧校准候选3.19437减少0.03759，但仍弱于Poisson的8/67、3.15287。保存为DO_NOT_PROMOTE；不把概率损失减小说成命中率提高。正则、温度网格与候选集是本轮开发选择，不是已经验证的最优超参。

本轮方法变更发生在看过旧末段之后，因此末段只能作开发诊断，不能重新称独立验证。不能继续追着这67场挑参数。活动模型不变；下一步需要按时间滚动更新基础专家、积累真正未见的同节点样本，并补合格xG/球员事实以形成独立增量，不用共享旧信息的更多门控代替数据。
