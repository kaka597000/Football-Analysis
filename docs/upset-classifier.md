# 独立冷门分类器 WCPP-UPSET-0.1

它是当前模型、test模型之外的独立影子研究输出。它不重新选择第一比分，也不将风险概率混入两套模型的胜平负或大小球矩阵。

冷门的标签必须明确：以命名机构赛前1X2去水概率定义市场热门，主队或客队为三项最大且概率至少50%时才属于本模块范围。分别输出热门赢球、平局、热门输球；热门不胜为平局与输球之和。“热门输球”与“热门不胜”不能混算命中率。均衡对阵没有符合定义的热门时拒绝分类。

训练采用独立的多项逻辑回归，按联赛分别训练，不混合男女、年龄、级别、赛事阶段。特征包括去水赔率、主客标识、严格日期之前的Elo、近期进失球/积分、同联赛间隔与冷启动标识；未知近期样本使用训练分区的中位数及显式缺失标志，不把未知当正常。

同一天的赛果在全部该日特征生成后才更新。训练/校准/留出测试按日期分开，校准区选择正则强度与研究报警阈值，留出测试不参与选择。历史B365H/D/A字段与已核实90分钟赛果来自真实档案，精确赔率采集时刻缺失，所以属于事后时间切分开发验证，不能称严格赛前快照或前瞻准确率。

初版覆盖英超、西甲、德甲、意甲、法甲、英冠、德乙、荷甲、葡超。亚冠等缺少已训练历史市场队列的赛事不借用其他分类器。阵容、伤停、战意、全赛事负荷及诚信系数尚未训练；低优势和模型相关特征不能证明卖分。

截至初版，九个联赛均未通过预先定义的优于市场基准门槛。因此启用为独立研究旁路，输出研究概率与未通过标记；不给可信高风险行动警报。校准区研究阈值即使触发，也只是 research_threshold_exceeded，不能追认为有效冷门识别。

默认预测入口 runtime/predict_active.py 在 upset_classifier 中单独记录结果。输入需要 wdl_quote：match_id、market="1x2"、verified=true、bookmaker、source_url、query_time、home_odds、draw_odds、away_odds，以及有则提供的 quoted_at。所有赔率是十进制。quotes.from_espn 可从保存的实际ESPN赛前摘要按对阵、时间和状态生成该字段；不得手填市场概率或从大小球报价猜测1X2。

若缺赔率、无训练赛事、存在中立场范围问题或不满足真实未来时间约束，返回ABSTAIN，不生成默认概率。旁路失败必须明确标记，保持两套比分模型结果。新模型不能用在其创建前的预测上，昨天赛后案例不能倒认命中。

独立使用：

    python runtime/upset/cli.py predict fixture.json --out upset-new.json
    python runtime/upset/cli.py review upset-records.json --results verified-results.json --out upset-review-new.json

复盘单独统计热门输球、热门不胜、报警查准率/召回率和完整分母；无有效报警时查准率为空，不记成100%。研究版不进入原Primary正式KPI，不重新登记原500+200，不修改Champion V21.5等既有版本。
