# 独立市场基准

research_program/market_expert.py 使用留存原始文件、实际采集/报价时点及赛事阶段校验，按provider/bookmaker/market/line分组；不将不同盘线的水位拼成变化，不把价格当作资金流。

H2H提供明确标记为未训练的比例去水基准。大小球包含走盘与半结算，不从两项赔率机械推导比分或二项概率；当前没有已训练的市场比分矩阵。

同场WDL比较分别报告覆盖、Top1方向、Brier和LogLoss，不以有报价子集替代全量。验证函数不认证输入的外部真实性或未见属性，必须配合留存证据、首次冻结与时间外队列使用。

测试覆盖真实截止时点、过期/冲突、跨线分组及完整分母。历史多时点覆盖和市场比分模型训练仍需真实数据，未证明对精确比分/实际大小球有增量收益；本模块不修改活动预测。
