# 用真实实验推进研究

用户在2026年11月17日明确要求减少过度防御性编程，大胆验证算法、权重和数据方案。第一推荐精确比分仍为第一目标；胜平负和实际盘口大小球分别核算。70%/80%是研究目标，实际成绩决定方法取舍。

## 执行方式

- 先跑可用基线，再完成具体候选的训练、同场比较和下一次未来预测。已有可运行输入时，不停在“缺数据、未晋级、继续观察”。
- 一个来源没有字段就实际调用合适备用来源。欧国联xG优先核验已能返回统计的BSD，不因ESPN无字段就结束。
- 汇总xG字段不一致时分别实验；逐射门合计另列。估算标记、字段差异和目录标记冲突保留为质量信息，不一律丢弃有价值的数值。
- 缺xG的历史行保持在总体中，用该行真实进球作为声明的基线回退。报告实际xG覆盖及回退数量，避免只保留容易的样本。
- 不用样本量或活动模型晋级条件阻止独立研究。效果差、无增益和负增益均是结果，继续针对原因迭代；不靠重复选同一留出集制造增益。
- 比赛身份、90分钟赛果、训练日期早于目标、旧冻结与工件哈希仍需真实。历史回填用于开发实验，下一批真实冻结用于前向评价。

## 本轮xG实验

使用独立入口 `runtime/nations_league/xg_research.py`。保持既有模型代码和工件，另拟合分级球队攻防。对每条历史比赛的目标进球量使用：

`研究目标 = (1 - xG权重) × 实际进球 + xG权重 × 提供方xG`

三种来源字段分别为 `expected_goals`、`xg.actual`、逐射门xG合计；权重为0.25、0.5、0.75、1，另保留权重0的进球基线。字段缺失时该行回到实际进球，权重1也不能称为全历史纯xG。该方法学习球队攻防参数，混合权重是事先登记的实验值。

按比赛日滚动拟合，每级独立；原实际赛果是评价标签，目标比赛本身的xG不能进入它的预测。10月作为开发选择窗口，11月12–16日作为已知赛果诊断窗口，两者均不冒充严格历史时点认证。所有预定方案保留，选定候选及基线进入后续未开赛赛事的独立冻结。旧18场计划不改写、不扩充为新实验首版。

比较精确比分、胜平负、原真实盘口结算、覆盖及概率质量；历史盘口不齐的部分继续比分/胜平负试验。未来能取得真实盘口的比赛直接保存选向和报价，避免再次出现有盘口却没有冻结选向的结算缺口。
