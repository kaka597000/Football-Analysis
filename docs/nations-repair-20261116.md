## 已修复的数据问题

ESPN summary 的 `competitions[0].groups` 有对象、列表两种结构。原解析器没有读取这个字段，造成真实已有分级证据未进入训练，2024 年 156 场全部遗漏。新解析器读取明确的分级名称，不从不透明 group ID 或球队当前等级倒推历史等级。

另有旧 summary 展示标签与该届 season、同 event ID scoreboard 冲突：例如旧赛季错误展示当前组名或通用 Final/Relegation Playoffs。只在赛季分级证据与精确同场 scoreboard 一致、球队与开球一致、剩余明确标签无冲突时剔除未绑定届次的展示标签，并记录来源裁决。明确 League A/B 冲突仍拒绝；不改原始响应或比分。

## 综合判断改进

后续欧国联综合分析填写 `decision_policy_version: WCPP-COMPREHENSIVE-REPAIR-1`、`override_validation_status: UNVALIDATED_MANUAL_RESEARCH`。比分、胜平负、实际盘口大小球分别判断。

`score_distribution_audit` 从原矩阵独立求胜平负；点比分 1–1 不等于平局概率最高。若人工方向不被任何引用模型支持，必须填写 `selection_evidence.wdl_evidence.reason/counterevidence`；实际大小球方向填写 `total_evidence.reason/counterevidence`，并保留原 `total_reason`、候选比分与零球/一球反证。缺项可冻结并保留覆盖，但不能进入 TOP3。此为证据完整性检查，不是人工判断已验证有效，更不是自动改分。
