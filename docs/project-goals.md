# WCPP项目长期目标

用户确认：2026-10-30，北京时间。后续开发、方法研究、训练、赛事分析与复盘均围绕本目标执行。机器可读定义见仓库根目录project-goals.json。

持续优化足球分析模型代码，深入研究并实际验证不同赛事的足球分析方法，提高未来真实赛前冻结样本的第一推荐精确比分、胜平负和实际盘口大小球命中率。

## 目标优先级

1. **最高业务指标：第一推荐精确比分Primary Top1实际命中率。**长期目标70%以上；不是给单场推荐标注70%概率，当前未证明达到。
2. **辅助业务目标：胜平负、实际盘口大小球实际命中率分别80%以上。**分别评估，不与比分混算，也不能替代Primary Top1证明升级成功。
3. **工程目标：数据可信、时点正确、执行可复现、采集高效、版本可追溯。**每次改动说明如何支持上述业务指标，不把模块数量、代码重构或训练完成当效果证据。

目标值是研究方向，不是达标承诺。先实测现有成绩，再报告同场配对净增命中、样本量、覆盖率、时间窗口和不确定性。

## 持续优化的执行闭环

- 每批分析：接口与缓存优先；核验赛事级别、男女、年龄、赛制及90分钟口径。按实际覆盖收集状态、主客差异、对手强度、xG/xGA、阵容伤停、积分数学战意、全赛事赛程、休息旅行和真实盘口；缺失保留，不猜字段。
- 每次复盘：按当前模型、test模型、综合判断分别统计，分开赛前、更新和滚球。拆分主客进球均值偏差、机会生成、转化/扑救、比赛状态和最终选分误差，记录保持、修复、补数据、实验或切换的决定。
- 发现可复现实现错误立即修复；数据缺失先补齐；新特征、新权重、模型融合或选分规则在独立test实验中逐项验证。比较同场、相同时点，避免只研究命中的案例。
- 按时间推进训练、验证、未见测试，预处理和基础参数只使用对应训练窗口。已看过并用于调整的历史测试集降为开发数据，最终仍以未来真实冻结表现验证。
- 深入研究统计模型、Dixon-Coles、进球相关/离散分布、机器学习、校准与动态融合；深度学习、强化学习可作为Python独立实验，须有适量真实数据与对照证据。不能因为方法新或模块多就直接接入默认链。
- 当前/test持续并行，综合选分独立、可审查；人工改分同时统计“模型错而改对”和“模型对而改错”。有稳定证据才按既有自主调整规范切换，失败可回滚，旧工件与冻结保留。
- 每次可交付修改完成后检查、提交、推送并核验GitHub。活动工件、数据库身份及训练截止与代码commit分别记录。

## 评估口径

比分只看预先指定的唯一Primary，不用Top3覆盖、方向命中或赛后最好版本替代。未给Primary的场次保留覆盖分母，单列待定率及完整批次表现。
胜平负分母仅包含预先明确选择胜/平/负且已有合格90分钟赛果的记录，同时保留整批覆盖信息。
大小球只按预测时记录的实际机构盘口结算，全赢、半赢、走盘、半输、全输分别统计；严格全赢率以非走盘的有效推荐为分母，半赢不算全赢。任何等价加权指标另列，不能替代严格口径声称达到80%。
比分、方向和大小球的分母独立；待定、失效、缺赛果、不适用或来源冲突不得偷偷剔除或补命中。不通过事后筛选容易比赛制造表面提升。
