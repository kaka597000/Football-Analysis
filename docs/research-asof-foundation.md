# 分阶段、按实际采集时点回放

`runtime/research_program/replay.py` 是独立研究基础，不调用活动模型或修改冻结。沿用现有V2来源/文件哈希/观测校验，另要求明确cohort、phase和provider，排除目标赛果、未来比赛、截止后采集、跨阶段及重复冲突。历史回放使用当前真实执行时间，不伪造过去now。

缺项返回None及实际样本量，不填0。首次知悉时间未知保持未知；较早的发布时间不能把后补下载的数据提前到历史cutoff。快照以内容哈希排他保存，篡改拒绝。

独立标签入口要求实际90分钟结束、采集时点及留存证据；不能只凭赛果日期宣称当时可用。市场和球员即时证据走各自时效契约，不混入历史均值。

测试使用合成数据，只验证时间/身份/阶段和存储规则，不作为足球成绩。旧历史first-known及原始文件缺口仍阻断正式时间外回测。算法实验应分别报告开发诊断和未来未见验证，不自动晋级。
