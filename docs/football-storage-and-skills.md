## 三个项目级Skills

可编辑源位于本仓库 `.agents/skills/`，通过项目AGENTS索引供后续任务读取；无需把密钥、数据库或冻结数据放进技能。它们是项目本地技能，不是已发布到ChatGPT工作区的云插件，不宣称本轮已经观察到宿主自动加载。

|技能|任务示例|实际职责|
|---|---|---|
|[赛前分析与冻结](../.agents/skills/context-wcpp-prematch-freeze/SKILL.md)|分析下一批比赛，核查模型适用性并冻结赛前结论。|身份/适用性、证据、双模型、综合选择、冻结和推送|
|[复盘与滚动验证](../.agents/skills/context-wcpp-review-walk-forward/SKILL.md)|复盘已冻结比赛，分别统计各轨结果并给出下一轮验证决定。|完整分母、逐轨结算、时间隔离、诊断和验收|
|[赔率证据分析](../.agents/skills/context-wcpp-odds-evidence/SKILL.md)|核查这批比赛的赔率变化，区分可用报价、陈旧数据和缺项。|同场同机构同盘时点对照、缺项和可用性|

指标语义引用[用户核心需求](user-primary-score-requirements.md)和[冻结规则](analysis-freeze-policy.md)：尤其区分唯一第一比分、每场多个比分候选与批次TOP3赛事，不能换名称后混合业绩。

## Drive副本流程

1. 先完成权威源报告、逐轨计算与冻结，验证原记录哈希。
2. 导出明确白名单内的报告/展示表与manifest，记录源仓库commit、源路径、SHA256、冻结ID、截止时点和版本。原始凭据及无关个人资料不进入副本。
3. 仅在当前会话实际提供Drive写入能力时上传；按逻辑目录 `Football-Analysis/Reports/YYYY-MM-DD/批次-版本/` 创建追加副本。Google Drive使用文件/文件夹ID识别目标，不能只凭重名覆盖。
4. 成功后登记返回的Drive文件ID、实际URL和上传时间。未调用、只生成本地目录或工具不可用时状态为 `NOT_UPLOADED`，不能写“已连接/上传成功”。
5. 无Drive工具时仍完成仓库推送，保留可上传副本及manifest；缺工具不阻断源码和数据交付。不自动安排定时同步或环境发布。

本轮当前工具目录未提供Google Drive读取或写入接口，未重新认证用户此前的连接状态，也未创建Drive目录。交付中的模型核查报告已准备为副本，连接可用后按上述流程上传即可；没有新建Notion或发布环境。
