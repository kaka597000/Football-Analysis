## 必须交付什么

每场先核实比赛分类，再综合双方实际情况，形成主要比赛路径，比较候选比分，最终给出一个唯一的第一推荐精确比分。概率矩阵提供统计基准和反证；综合判断需要另外说明事实、推断、选择原因和关键不确定性。不得只把矩阵最大格子重新命名为“综合第一推荐”。

第一推荐比分实际命中率70%以上是未来完整赛前推荐样本的目标，不是要求给所选比分标注70%的概率。胜平负和实际盘口大小球的实际准确率目标分别为80%以上；均尚未证明达到。唯一正式最高KPI仍为未来冻结Primary精确比分Top1，不能以其他指标替代。

## 分析顺序

1. 分类：赛事级别、男子/女子、年龄、联赛/杯赛/友谊赛、阶段、单/双回合、首/次回合、总比分、中立场、90分钟口径。不得凭“某联赛一定对攻”“杯赛一定有剧本”代替证据。
2. 状态与实力：适合该赛事的近期正式比赛、主客差异、对手强度、当前赛季及可用进球过程；友谊赛与正式赛分开，历史样本覆盖不足明示。
3. 过程：真实xG、射门、射正与机会质量；缺失不填造，赛后过程不能用于该场赛前特征。
4. 战意与赛制：积分、剩余比赛、晋级/争冠/保级/种子位数学状态、平局的实际意义；“需要赢”不是必然获胜的证据。
5. 阵容与体能：首发、替补、伤停、停赛、关键角色替代、实验阵容；前14天及后7天全赛事安排、连续客场、加时、旅行与时区。预计首发不冒充已公布首发，接口空窗不冒充真实休息。
6. 公开信息与异常：教练、球员、足协、俱乐部表态；相关可核证诚信信息。盘口波动、冷门或战意不足不能直接证明卖分。
7. 比赛路径：控制节奏、压制/反击、追分、双向得分、领先后收缩和开放级联的触发条件。给出主要路径、替代路径及反证，再比较至少两个合理比分候选，选一个第一比分。
8. 市场放在最后：按真实机构、盘口、两侧报价和时间校验。不能直接跟随市场最高选取率，也不能仅因反市场而选冷门。
