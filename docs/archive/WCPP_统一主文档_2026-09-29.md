## 4. PreMatch Context / Motivation / Integrity Audit

每场比赛进入数值模型前，必须先搜索并结构化：

- 近期真实状态；
- 主客场拆分；
- xG、射门、机会质量（可得时）；
- 积分、排名、争冠、保级、晋级、种子位等数学状态；
- MUST_WIN / DRAW_ACCEPTABLE / DEAD_RUBBER；
- 杯赛首回合/次回合与总比分；
- 轮换、实验阵容、首发不确定性；
- 赛程拥挤、休息天数、旅行与时区；
- 教练/球员/足协/俱乐部公开表态；
- 市场价格和成交时间序列异常；
- 公开诚信/比赛操纵风险信息；
- LOW_INTENSITY_CONTROL / OPEN_CASCADE_RISK等比赛状态路径。

### 4.1 不同赛事的近期状态窗口不同

- 五大联赛：近期5–10场 + 主客场 + xG/机会质量；
- 低级别联赛：更强调阵容稳定、场地、连续客场、赛程密度；
- 杯赛：联赛状态只作背景，必须加入轮换、回合、总比分和晋级状态；
- 国家队正式赛：近期国家队窗口、可用名单、旅行、小组排列；
- 国家队友谊赛：实验性、换人、球员管理权重更高；
- 女足/青年/亚运：只使用同cohort历史和本届实际资格规则。

### 4.2 “控分”与“卖分”严格分离

合法竞技策略可以进入模型，例如：

- 平局即可晋级；
- 两回合领先后主动降节奏；
- 已锁定名次后轮换；
- 为避免伤病管理主力分钟；
- 小组末轮不同结果对应不同种子/对手。

这些只能标记为`SPORTING_INCENTIVE / SCENARIO`，不称为比赛操纵。

非法比赛操纵只有在以下公开可核证来源支持时才能升级：

- FIFA / UEFA /洲足联/足协官方；
- 执法机构或法院；
- 官方诚信部门；
- Sportradar / IBIA等专业诚信机构公开告警、调查或确认案件。

固定纪律：

```text
market anomaly != match fixing
matched volume != bettors count
odds movement != insider evidence
rumor != verified manipulation
```

## 9. Regime-Conditional Margin–Total Calibration 0.1｜SHADOW

模型ID：

`WCPP_REGIME_CONDITIONAL_MARGIN_TOTAL_0.1_SHADOW`

结构：

```text
Frozen Base Matrix
→ Total Regime
   LOW=0–1 / CENTER=2–3 / HIGH=4+
→ Signed Margin
   D0 / H1 / A1 / H2 / A2 / H3+ / A3+
→ IPF / KL-style minimum-change projection
→ 64-cell exact-score rerank
```

核心约束：

```text
minimize KL(Q || P_base)

subject to:
Q(T-regime) ≈ calibrated Total Regime
Q(Margin bucket) ≈ calibrated Margin
sum Q = 1
```

不直接修改原Football λ。

### 9.1 Development结果

五大联赛1751条历史replay，时间隔离：

- Train：2025-08-15～2026-01-31，N=1025
- Test：2026-02-01～2026-05-24，N=726

| Branch | Top1 | Top3 | Top5 | Top10 | Top20 | Score LogLoss |
|---|---:|---:|---:|---:|---:|---:|
| Raw Poisson | 13.09% | 32.09% | 49.72% | 78.79% | 96.42% | 2.8838 |
| Total only | 12.53% | 31.96% | 49.31% | 77.82% | 96.42% | 2.8848 |
| Margin only | 12.26% | 33.06% | 49.17% | 78.51% | 96.69% | 2.8932 |
| Total + Margin | 13.22% | 31.54% | 49.59% | 77.82% | 96.56% | 2.8936 |

结论：

- Top1仅+0.14pp；
- Top3、Top10下降；
- LogLoss恶化；
- 当前数值Candidate **DO_NOT_PROMOTE**。

Mean-preserving三状态全局dispersion实验最大状态权重99.9053%，几乎退化为单状态。

因此：

> 禁止全局统一扩大dispersion；Regime必须按Competition/Cohort独立训练。
