# 澳超比赛开放性：赛前综合判断要求

用户确认：2026-10-16，北京时间。用户强调澳超比赛相对开放，后续澳超分析必须把这一点纳入综合判断。它是需要逐场验证的联赛背景，不是固定加球参数、必然大球或未经训练的模块权重。仅适用于男子成年澳超常规赛；季后赛、女子和青年分别核验，不能借用。

## 必须执行

1. 先取当季及适当近期窗口的联赛进球水平、双向得分、零封和4球以上比例作背景，再审查两队同主客攻防、对手强度、真实可得xG/xGA与射门质量。窗口、样本数和缺项必须记录；历史均值不是本场预期进球。
2. 主客分别审查零球、1球、2球及3球以上路径，关注防线空间、攻防转换、首发和替补攻击能力、后场伤停、休息及旅行。仅有进球数据不能宣称已证实比赛节奏或机会质量。
3. 比较至少一个继续开放的路径：领先方继续进攻、落后方压上、双方得分后的进一步开放；同时保留控节奏、低效进攻、轮换、天气或其他有实际证据的低比分反证。不能只因领先就假定双方停在2比0，也不能因联赛标签直接选3比2。
4. 综合第一比分逐场由证据和候选比较决定；统计专家矩阵保持原样，若人工改分独立冻结并记录原因。缺矩阵不能生成假的均值/80%区间/概率；缺关键证据继续待定。
5. 大小球使用实际机构、盘口和时间快照。比赛开放不等于任意高盘口都值得选大；尤其需要对照3、3.25、3.5及更高实盘的具体结算边界，不统一套2.5。
6. 复盘分别统计主客与总球均值误差、点比分误差、零封误判、3球以上主队及4球以上总球漏判。把“开放性/高比分尾部模型是否改善Top1”作为可验证研究问题；仅当预登记、时间外及未来冻结证据支持时再调整数值模型。不改现有专家工件、current/test或旧冻结。
