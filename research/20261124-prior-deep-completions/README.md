# 球队危险区域传球能否改善赛前比分

**本轮决定为淘汰当前配方。** 加入球队近六场的危险区域传球数后，2025/26 赛季首选净多中 11 场。到了能证明输入已在赛前保存的 25 场，首选净增 0，前三少中 1 场，胜平负少中 2 场，实际比分的平均对数损失从 2.9712 升至 3.0296。保留现有模型与 R7 的 192 场队列。下一次研究先核验近期球队数据的时点与覆盖。

## 输入从哪里来

使用 2020/21 至 2024/25 五季共 8,982 场分别拟合五个联赛的进球率，最晚训练日为 2025 年 5 月 25 日。开发窗整季从 2025 年 8 月 15 日到 2026 年 5 月 24 日，按源赛历日期整日向前滚动。历史赛季的原始输入实际抓于 2026 年 10 月，旧比赛当日的来源首次发布时间未知。该窗可验证训练先于测试；发布时效只在 11 月另验。

基线复用 `score_form.summarize/features`，双方共同使用近六场进球与失球、xG 与 xGA、休息天数、主客场。候选固定全部基线系数，只增加一个联赛内拟合的系数，将进攻方过去危险区域传球 `deep` 和本场对手过去允许的 `deep_allowed` 作为额外信息。两项须由上场双方相反视角核对，少于三场有效记录则两边原样返回基线。历史窗启用 1,607/1,752，其余 145 场均保留；后窗启用 25/25。两边共用比分、前三、胜平负和实际大小球决策。此项检验的是进攻深入程度在已有 xG 之外带来的增量。

## 下一步取舍

同一个球队最新输入，在开发窗距离目标比赛的中位数是 7 天，后窗是 41.5 天（21–43 天；按两队各一条计算）。样本无法把信息陈旧的影响与比赛构成分开。下一步优先查有逐日赛前留档的最近几轮非点球 xG 与失球质量，再决定是否值得一次新的同场对照。已对这条线索做了字段覆盖检查：35 份原件的 22,062 个球队场次均有 `npxG` 和 `npxGA`，2026/27 的最新观测仍停在 10 月 11–12 日。查找时先列每队本应有的过去六场及缺口，再比对原始采集时间。它的预测效果尚未测试。当前配方止于此次回放，已锁队列照原协议等待复盘。

## 离线复算

从本草稿源码仓根目录执行。Python 3.12.14、NumPy 2.3.5、SciPy 1.17.0、scikit-learn 1.8.0。`DATA` 指向含 `466fd626` 与 `a6d45024` 对象的数据仓。`RESTORED` 是 11 月 2 日恢复出的 `WCPP` 上级目录；只读原有归档。用户证据包《球队攻防信息同场回放_20261124.zip》含哈希核对过的 `inputs/`、`replay/`、`grade/` 和 `tables/`。解压至 `OUT` 后可直接运行 `model_study.py` 和 `grade_study.py`；独立重建原始球队输入与身份桥接时再运行 `build_inputs.py` 和 `match_fixtures.py`。`inputs/archived-totals.csv` 保留本次查过的合格双边报价，原始归档位置与指纹见包内 `market-audit/`。确认大小球原件和认证赛果仍使用固定 Data Git 对象。回滚研究只需关闭本草稿。

```bash
S=research/20261124-prior-deep-completions
export PYTHONPATH="$PWD/runtime" OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1
DATA=/path/to/kaka597000-Football-Analysis-Data
RESTORED=/path/to/restored-backup
OUT=/tmp/prior-deep-study
python "$S/build_inputs.py" --data "$DATA" --restored "$RESTORED" --out "$OUT/inputs"
python "$S/model_study.py" --inputs "$OUT/inputs" --out "$OUT/replay"
python "$S/match_fixtures.py" --data "$DATA" --restored "$RESTORED" --inputs "$OUT/inputs" --out "$OUT/inputs"
python "$S/grade_study.py" --data "$DATA" --estimates "$OUT/replay/estimates.jsonl.gz" --bridges "$OUT/inputs/bridges.csv" --quotes "$OUT/inputs/archived-totals.csv" --out "$OUT/grade"
python "$S/export_tables.py" --grade "$OUT/grade" --out "$OUT/tables"
python -m unittest discover -s "$S" -p test_study.py -v
```
