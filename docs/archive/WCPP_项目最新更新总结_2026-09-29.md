# 5. Regime-MT-KL当前结论

目标：

解决：

`CENTER_COMPRESSION / TWO_TAIL_MISS`

即：

- 0-1 / 1-0 / 1-1 / 2-0 / 2-1过度集中；
- 0-0等低尾进入Top Rank不足；
- 4+ / 5+ / 6球高尾进入Top Rank不足。

Shadow结构：

```text
Frozen Base Matrix
→ Total Regime
   LOW = 0–1
   CENTER = 2–3
   HIGH = 4+
→ Signed Margin
→ KL/IPF minimum-change projection
→ 64-cell rerank
```

五大联赛Development时间隔离测试：

```text
Raw Top1      13.09%
Regime+Margin 13.22%
Lift          +0.14pp

Raw LogLoss   2.8838
Shadow        2.8936
```

结论：

`DO_NOT_PROMOTE`

原因：

- Top1提升过小；
- LogLoss恶化；
- Top3 / Top10没有同步改善。

同时，全局mean-preserving dispersion实验几乎退化回单状态，因此：

> 禁止使用一个全局dispersion参数覆盖所有赛事。

下一步只能做competition-specific / cohort-specific Regime与Dispersion。

# 8. 最新Top 3精确比分推荐规则

以后每次整批分析完成后，必须固定增加：

## 「Top 3 最推荐精确比分」

但这个Top 3不能简单等于：

```text
正确比分赔率最低的三场
```

也不能为了追求差异故意选择高赔率比分。

最新固定流程：

```text
① Market-Blind WCPP Score Probability
   先完全不看Correct Score赔率

        ↓

② Structural Score Adjustment
   Competition Router
   Regime
   Margin
   Context
   Lineup
   Motivation
   URE

        ↓

③ Market Sanity Check
   最后才检查Correct Score市场是否出现严重冲突
```

原则：

> 精确比分命中率优先，不以“赔率高”作为价值，不以“赔率低”作为唯一正确理由。

Market只做最后校验，不能主导Score Top1。

# 9. Raw Mode与Structural Override进一步收紧

近期复盘显示：

- 很多正确比分已经存在于Pair@2 / Top5；
- 问题常发生在Rank Head；
- 过多Structural Override可能把Raw正确候选压下去。

因此最新纪律：

```text
如果没有足够独立Football证据
→ 不Override Raw Mode

如果Override
→ 必须记录清楚具体证据
→ 市场单独不能作为理由
```

Top 3比分推荐同样遵守这一规则。
