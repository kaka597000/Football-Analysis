# 五大联赛赛前球队攻防与比分选择实验

适用范围为英超、西甲、德甲、意甲、法甲男子一线队的常规联赛，评价使用90分钟赛果。拟合、逐场推断、首次前向登记和结算均有独立入口。研究登记使用独立轨道。

## 球队历史与选分

每个联赛分别估计主客场进球均值和各队攻防偏差。回归需要知道交手对手。历史权重半衰期为120天，球队岭惩罚为3，主客场联赛均值的岭惩罚为20。队伍首次出现时沿用联赛先验，并保留已知对手的强度。观察量的三个对照分别使用往场进球、往场盘口推得的进球均值，以及80%往场盘口均值加20%往场实测xG。缺xG时用该场已完成的进球。只有全日预测结束后才将该日赛果加入历史。

2019/20至2023/24用于累积历史和拟合原六场状态模型，2024/25用于选型。后续两个已检阅时段用于复核。首选与备选组合是在看过初轮各模型的分项成绩之后新增的研究。选型期保留六场模型的首选，其余两个席位取球队强度排序中与首选不同的前两项。胜平负与大小球分别使用获选的强度模型。遇合格同机构胜平负和大小球双盘时，使用选型期胜出的同期市场基线。模型输出携带用于首选、备选及方向的分项依据，矩阵用途见 `matrix_role`。

## 复算与赛前运行

1. 运行 `scripts/train_prior_team_strength.py --help` 查看日期隔离回放的输入。赔率矩阵可从带比赛ID和源文件校验的缓存载入，也可从原始赔率计算。
2. 运行 `scripts/select_prior_score_heads.py`，输入上一步的逐场输出及分项选型协议。选型季与后续复核分别留档。
3. 使用 `scripts/update_prior_team_strength.py` 输入新增的已完赛赛果、双方、报价和经核验的赛后xG。该入口先作逐日回放，再生成用于未来赛事的工件。新补取的赛后xG只进入未来工件。
4. 使用 `scripts/capture_public_club_markets.py --fixtures FIXTURES --team-ids TEAM_IDS --out CAPTURE` 取得已登记球队的赛前公开报价。球队映射同时绑定 ESPN 队伍ID、InferSports 队伍ID及双方名称。每个实际响应都附来源、采集时刻和原始字节哈希。程序逐个检查报价行的时间、全场范围、机构、开售状态及盘线。当同一机构开多个盘时，选择两边赔率最均衡的合格盘。比较机构时优先选有双盘且两个市场中较早的报价时间最新的机构。
5. 将 `CAPTURE/prepared-fixtures.json` 和新工件传给 `scripts/forecast_kpi_candidate.py`。有合格大小球单盘时可以冻结大小球。两盘均缺时仍保留可计算的比分与方向。
6. 完赛后用 `runtime/research_program/paired_kpi_inference.py audited` 核对首版冻结与原始赛果。首选、三选、胜平负、实际盘口全赢各有分母，走盘单列。

与上述推断并行，`displayed_exact_scores.compare` 支持机构页面直接展示的全场精确比分赔率。显式比分按十进制赔率从低到高排序，同价优先同页胜平负和总球推算概率，其次按主客进球数排序。所有“其他比分”保留为独立分组，输出同时报告可能影响前三排序的分组价格。页面观察时间与逐项报价时间分别归档。
