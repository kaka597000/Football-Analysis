# 第一比分综合决策规范

用户要求更新：2026-10-13，北京时间。适用于未来赛前分析；不修改历史推荐或追认正式冻结。

## 目标与现状

目标是正式赛前保存的唯一第一推荐比分，在未来完整推荐样本中的实际90分钟精确比分命中率达到70%以上。不是要求单场模型概率达到70%。胜平负和实际盘口大小球的实际命中率目标分别为80%以上。目标尚未得到证明；报告样本数、覆盖率、待结算与置信区间，不能删掉失误或用赛后改选实现目标。

现有WCPP-MAIN-1.2统计模型不直接选市场热门比分，但尚未完整实现以下九类综合决策。六块上下文审计和经过验证才可启用的部分数值修正，不等于九类信息已全部融合。`primary`保留为统计参考比分，`comprehensive_primary_ready=false`；现有研究矩阵不包装为综合第一推荐。

## 每场必须留下的证据账

先确认赛事、级别、男女、年龄、阶段、主客或中立场、开球时间及90分钟口径。双方分别核查，适用全场的规则和异常可共同登记。

| 类别 | 核查内容 | 必须说明的限制 |
|---|---|---|
| 状态 | 适合该赛事的近期窗口、主客差异、对手强弱、当前赛季结构 | 窗口与理由；新赛季/升降级不可混同旧分组 |
| 过程 | 可得xG、射门、射正、机会质量及进失球偏差 | 缺少xG就记未知；不同供应商定义不直接拼接 |
| 战意 | 积分、剩余场次、晋级/争冠/保级/种子位数学状态、平局是否有利 | 给出规则与计算；教练表态不代替数学条件 |
| 赛制 | 单/双回合、按本场主客方向的总比分、客场进球规则、中立场、加时点球 | 输出比分只针对90分钟及补时 |
| 阵容 | 已公布首发、替补、伤停、停赛、实验阵容及关键角色替代 | 预计首发与官方首发分开；不只按缺员人数推断影响 |
| 体能 | 前14天与后7天全赛事安排、休息、连续客场、加时、旅行和时区 | 联赛空窗不等于休息；开球间隔不等于实际休息时长 |
| 公开信息 | 教练、球员、足协、俱乐部可核证表态和公告 | 保存原文、日期、来源；报道与官方声明分开 |
| 路径 | 控节奏、追分、双向得分、开放级联风险与触发条件 | 不把比赛进程写成确定事实；说明支持和反证 |
| 异常 | 同机构带时间的盘口变化、公开诚信调查/处罚与相关信息 | 单一赔率变动不是操纵证明；无信息不是已证清白 |

每条事实保存来源URL、来源层级、发布/采集时间、支持的具体判断、已知/未知/冲突状态。证据必须在推荐截止时间可见。中国体育彩票官网及镜像禁访；可使用已获授权的澳客、公开官方来源及5DollarFootballAPI，密钥不得留档。

## 从证据到一个比分

1. 用同类赛事的足球数据产生候选比分矩阵，提供独立于市场的基线。
2. 根据九类证据建立主要比赛路径、替代路径与反证，明确哪些因素可能改变进球强度、双方相关性或比分排序。不能用“必胜战意”“杯赛剧本”等标签直接改参数。
3. 只有经时间隔离验证有效的融合方法才可改变数值矩阵或候选排序；没有验证的因素作为定性审阅及是否推荐的依据。不能手填权重、伪造概率，或把没有融合的基线称综合推荐。
4. 市场只在最后用于校验和经验证的有界重排。分歧先检查身份、时间、阵容和数据质量，不自动追随热门，也不为反市场而反市场。目前市场数值重排没有启用。
5. 完成后保存一个唯一的综合第一推荐、选择理由、原基线、关键反证、真实盘口和截止时间。若缺少会改变判断的关键资料，保留观察稿而不强行给正式推荐；同时公布覆盖率。

比分、胜平负与大小球应来自一致的最终分布；精确比分首选与胜平负累计类别可以不同。人工定性判断若将来单独试验，须单独登记方法与验证群体，不冒充矩阵概率或混入原模型业绩。

## 诚信信息口径

可登记“公开调查”“公开处罚”“待核证线索”“未找到可核证信息”。只有来源支持的具体事实才能呈现。异常盘口、战意不足、实验阵容或爆冷均不能直接推断卖分，也不能以传闻为球队或球员定性。不把赛后异常用于反写赛前证据。
