# 先判断单队进球，再选择综合第一比分

用户确认执行：2026-10-15，北京时间。适用于所有后续比分分析，当前模型、test和独立实验轨分别展示，不混用结果。

## 固定分析顺序

1. 核实赛事分类、双方身份、阶段、90分钟口径与赛前数据截止时间。
2. 双方分别核查历史xG/xGA、近期进失球、对手强度、主客差异、首发/伤停、赛制战意和体能。保留来源、时间、缺失与冲突；区分已进入数值计算和仅用于定性判断的信息。
3. 从各轨实际联合比分矩阵计算双方进球边际分布，先展示主队及客队各自的预期进球均值、进球区间及零球/至少2球/至少3球概率。
4. 再根据双方互动，写主要路径、替代路径和反证：压制/反击、领先后的选择、追分能力、零封和开放风险。不能仅把两队各自平均状态相加。
5. 比较至少两个有依据的联合比分候选，说明为何选择其中一个，给唯一综合第一比分或证据不足待定。统计Top1与综合选择分别留档。
6. 发布前保存实际输出及冻结回执；新消息更新时追加版本。赛后分主客检查进球估计及区间，再评价联合比分，不用单队区间命中替代精确比分Top1。

## 数值口径与展示

- 历史xG/xGA是机会质量数据；本场预期进球均值是预测分布的数学期望；进球区间是分布的一段整数范围。三者不能混称，均值2.4不表示恰好2或3球的概率为100%。
- 主队边际为矩阵按客队轴求和，客队边际按主队轴求和。每轨使用其实际矩阵，禁止复制另一轨的区间或概率。
- 默认展示中央80%等尾区间（10%至90%分位数），同时保存并可展示该整数区间的实际模型概率质量。离散分布的实际覆盖可能高于80%；这是模型内概率，不代表已证明历史或未来实测覆盖80%。不能为了给出2—3球而手工缩窄。
- 区间不是硬边界，不把主队2—3球和客队1—3球机械拼成某个比分；联合比分还受双方相关性及比赛路径影响。区间外候选应说明属于尾部/替代路径，不能删除其概率。
- 均值和区间均须来自真实计算。缺矩阵/模型拒绝时明示数值不可用；如给定性进球判断，另标“定性研究、未校准”，写证据及缺项，不伪造覆盖率。
- 伤停、战意等尚无验证系数的定性因素，可影响独立综合判断；不能暗中修改矩阵、进球率或给人工区间套用原矩阵概率。数值修正须独立实现、验证、标版本。

## 冻结与复盘

每轨保存矩阵哈希、比分轴说明、边际分布、期望值、区间方法、名义覆盖与实际模型概率质量。后续复盘保存主队/客队均值有符号误差、绝对误差、区间命中和宽度，跨完整样本评估实际覆盖率；联合Top1、总球、胜平负和真实盘口结算继续独立统计。

该更新增加可核查的中间判断与展示，不改变现有模型参数、矩阵或Primary，不构成准确率提升证明。旧冻结记录保持原样，不为补字段改写历史。
