# 盘口备用来源实测与新预测接入

本轮由 Luna 实际调用既有环境凭据；没有购买套餐、关闭 TLS、改活动参数或回填首冻。实测窗口为北京时间 2026-11-12 23:45 至 11-13 00:06。

## 真实结果

| 来源 | 本轮证据 | 当前可用范围 |
|---|---|---|
| The Odds API | 两次 totals 请求均 200，各消耗 1 quota unit；最终保留逐字节原文及独立 ESPN 身份原文 | 8 场欧国联、93 条单机构全场大小球报价；8/8 通过新输入挂接及原文价格复核 |
| BSD | 赛事和赔率接口 200；英格兰—克罗地亚有 O/U 2.5 双边报价、来源更新时间 | `Consensus`、5 家聚合；仅市场参考，不能充当某一机构可结算盘口 |
| InferSports | 初次域外比赛盘口 200；随后欧国联盘口 401，响应为 `Invalid or revoked API key` | 未取得项目内合格新报价；同一环境变量及 Bearer 构造已复核，不能声称稳定备用可用 |
| 5Dollar | 状态 200，Community；查询的两日赛程为空；带 odds 的请求 403 | 未验收单机构盘口；仅凭 403 不能断言具体套餐原因 |
| API-Football | `/status` 返回 Cloudflare HTML 403 | 无法据此判断密钥有效性；本批停止 |
| TheRundown | 当前绑定的官方端点返回 Cloudflare HTML 403 | 无法据此判断密钥有效性；本批停止 |
| OpenFoot | 本轮未重试；既有文档描述的是模型 fair odds | 不当作真实机构盘口 |
| football-data.org | 本轮未重试；11 月 10 日留存结果提示启用 Odds-Package | 未确认当前盘口权限 |

The Odds API 当前环境绑定可用，与 GitHub Actions Secrets 管理接口的 403 是不同问题。环境凭据不会自动进入 Actions；此前实际任务报告 `MISSING_CREDENTIAL`、零请求。切换提供商也不能绕过这项部署权限。没有把任何明文密钥、认证头或含密钥 URL 放入仓库。

## 代码及部署边界

- `market_snapshot.py` 可显式选择欧国联或现有七个国内联赛，并传入 UTC 日期与报价最大年龄。欧国联要求独立来源确认 A/B/C/D 级别。七联赛仅有离线范围回归，本轮真实报价验收只覆盖欧国联；未知球队别名不模糊配对。
- `infer_market_snapshot.py` 为已核验的欧国联 A/C 来源映射提供独立适配器。使用行级 `as_of`、单机构、全场市场、完整双边价格；遇到 401/403/429 停止该服务。其测试通过不代表本轮真实盘口权限通过。
- `market_bridge.py` 复核快照、赔率原文、独立身份原文及 Infer 提供商事件原文；按固定来源/机构顺序选有效报价。当前部署顺序为 The Odds API、InferSports，机构优先 Pinnacle，其余字典序；不依据预测结果挑选盘线。相同最新时间有冲突盘线或价格时跳过该机构。
- `prospective_cycle --market-dir ...` 仅对新输入挂接盘口。缺失盘口继续保留比分/胜平负；已捕获、受保护首冻、完整或部分恢复记录不挂接新价。旧 80 场不能因此补成大小球样本。
- 数据仓库现有任务增加 `market_bridge.py` 传输层覆盖及 `--market-dir`，锁定推理基版仍为 `6639867d502a2dfe53a9a235c8761f8ee6b91533`。不复制新推理源码、不自动切换活动工件。
- 当前定时采集仍显式为欧国联；未对七联赛盲目扩大付费额度消耗。未来国内新队列须明确对应联赛/日期采集后再首冻。该接口支持不等于所有联赛已有真实覆盖。

实际报价最大年龄按既有前向协议上限 3600 秒指定，抓取时点不替代来源报价时点。保留快照超过有效窗口后自动失去接入资格；一次聊天内采集不代表持续定时采集已经恢复。
