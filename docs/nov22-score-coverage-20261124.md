每场共用综合首版截止、已经给出的第一比分、当时引用的两套矩阵和同一实盘快照。30 场的盘线均通过原报价时点校验。一次调用已有 `WCPP-SCORE-COVERAGE-1` 输出两种排法。概率排序以两套矩阵等权均值取两个备选。路径覆盖仅在达到既有概率和覆盖条件时替换较低的备选，沿用默认最低路径概率 0.30、允许的概率质量损失 0.03。没有在这 30 场上选择参数。规则源码在首版复盘之后才进入仓库，结果属于日期隔离的开发重放。三个实际展示比分始终直接取赛前首表。[既有规则源码](https://github.com/kaka597000/Football-Analysis/blob/52450012497bc43da4f13a4228b17a3f27b27a67/runtime/research_program/score_coverage_policy.py)

## 离线复算

在源码仓根目录执行，使用项目 Python 依赖。数据仓本地需含上述赛前与复盘两个 Git 对象。命令读取指定提交，与数据仓当前检出的分支无关。输出 JSON 包含每场的展示原序、两种备选、冻结哈希、两轨矩阵概率名次、共同截止、改对改错的比赛 ID。

```bash
python scripts/replay_nov22_score_coverage.py /path/to/kaka597000-Football-Analysis-Data > /tmp/nov22-score-coverage.json
```
