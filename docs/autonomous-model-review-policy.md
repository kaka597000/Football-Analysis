# 复盘后自主调整模型

用户授权：2026-10-15，北京时间。复盘后由助手自行判断是否调整模型，以及需要积累多少场分析和复盘再调整；不为常规修正、实验、符合证据条件的版本切换或回滚重复询问用户。此授权优先于旧文档中需要另行确认晋级、机械等待固定场次的限制；不等于立即切换模型，也不重新注册旧500+200实验。

## 每次复盘必须形成调整决定

记录以下之一：保持、补数据继续观察、修复实现、建立实验、调整活动版本、回滚。写清本次样本与累计样本、版本/赛事/阶段、覆盖和缺失、Primary Top1、同场净增减、总球及概率诊断、误差原因证据、决定理由与下一检查条件。保持原模型也是需要解释的决定，不能复盘后只列赛果。

- 身份错误、标签泄漏、主客方向、时间、盘口结算、加载/路由、未使用实际工件等可复现缺陷：发现后立即修复并做针对性验证，不等待凑够比赛；保留旧输出及其错误状态，不改写历史。
- 有重复模式但证据不足：补充数据并建立独立实验，不凭单场惨败或单场大比分直接改进球率/权重。
- 数据、特征、模型或比分选择规则变化：先在实验轨与旧版本同场比较，区分数据修复、算法变化和人工改分；有稳定且有实际意义的Primary Top1改善、合理不确定性和损失/覆盖保护证据时，可自主切换符合条件的活动版本并报告，无需再次请求确认。
- 出现已证实缺陷或预先约定的持续退化，可自主停用/回滚，记录触发依据。实验无效则保留失败记录并停止扩大搜索，不强迫每次复盘都改模型。

## 何时评估，由证据决定

不统一规定每10/50/100场必须调参。根据独立比赛数、可用比赛周、联赛和赛制、数据覆盖、效应大小、配对差异与不确定性确定观察期。不能把主客两行、多个预测版本、重复赛果当更多独立样本。

每项实验开始前保存候选范围、评价口径和下一检查条件；只能依据已到达的合法数据更新条件，不能看成绩后择有利窗口。反复查看同一数据不能当成新增验证，必要时采用更保守的序贯评估。已经用于改规则/选参数的比赛成为开发数据，后续另看未参与选择的时间窗口及真实未来冻结样本。

历史回溯可筛选候选，不能冒充未来冻结实绩；新版本的证据必须说明属于哪一轨。方向、Top3、大小球或训练拟合改善不能代替Primary Top1。统计矩阵首选与综合人工首选继续分别评价。

## 切换与留档

当前模型、test模型继续独立，单次实验尽量保留一个不变对照；不赛后混合两者的最佳成绩。调整时保存旧工件与注册表、新版本和哈希、数据截止、实际参数、同场结果、切换时间及回滚命令。检查真实入口确实调用新版本，不静默回退。

所有后续实际分析发布前冻结；临场更新追加版本，赛前/滚球分开，不倒签。冻结、复盘和调整决定均保留。该规则不授权购买、订阅、发布外部产品、发送消息或新建定时任务；自主判断在实际分析和复盘工作中执行，不声称后台已持续运行。
