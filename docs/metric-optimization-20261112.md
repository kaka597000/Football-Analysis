## 固定权重实验

输入为五大联赛8,685场已被开发使用的逐月时间外预测。固定5,272场选参、1,717场门控、1,696场末段诊断；各赛事独立，按日切分。选择概率混合 `P=(1-alpha)×goals_only+alpha×expert`，alpha网格为0、0.25、0.5、0.75、1；专家仅原生尺度的 `fresh_missingness` 与 `opponent_residual`。门控失败立即退回研究基线，不试第二名、不根据末段反复改参。

|---|---|---|---:|---:|
| 英超 | 原研究基线 | 保持 | 46→46 / 422 | 193→193 |
| 西甲 | opponent_residual，alpha=0.5 | 拒绝，退回 | 50→50 / 329 | 168→168 |
| 法甲 | opponent_residual，alpha=0.5 | 拒绝，退回 | 32→32 / 334 | 157→157 |
| 德甲 | 原研究基线 | 保持 | 23→23 / 261 | 128→128 |

| 合计 | 仅意甲混合不同 | **不晋级** | **190→189 / 1,696** | **826→836** |

总体比分净减1，日期聚类95%净命中率区间约[-0.502%，+0.383%]，包含0。比分log-loss为2.955985→2.954121、WDL Brier为0.617023→0.616583；这些改善不能替代第一比分。没有本实验合格实盘大小球分母。这里的alpha是新研究混合参数，不是活动DC/ML融合系数。

原214条 DC/ML 首版重建固定网格也复算：76场有合格赛果，Current/Test比分命中3/5；alpha=0、0.25、0.5、0.75、1分别为3、4、5、6、6。其余118场缺可核赛果、20场未来待定。没有据此重选活动alpha。历史重建与真正前向候选分开。

另用较广的已有缓存补核3场FT，独立报告79场结果：Current/Test为4/6，alpha网格为4/5/6/7/6。增加来自来源覆盖，不是代码修复提高预测；没有混写原76场同样本对照。

1–1占研究基线首选1,287/1,696，实际185/1,696；平均模型P(1–1)=11.384%、实际10.908%。这是首选集中与平均概率校准的不同问题，不靠手工加球或压低1–1频率修饰结果。253份留存月度训练清单的已知日期无越界；预测文件缺1,090个暖启动训练ID日期，原始first-known也未认证，所以不称全新留出或严格历史时点认证。
