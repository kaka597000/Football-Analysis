# 范围内缺失双轨的研究入口补齐

本批保留 `WCPP-DUAL-4`、原 38 个工件、旧冻结和自动任务。新增 opt-in `runtime/research_pair_service.py`，有原活动研究路由时优先调用原 Current/Test；没有时才读取显式 `WCPP-RESEARCH-PAIR-REGISTRY-1`。两条真实归一分布缺一即失败，禁止空壳、借其他赛事模型或静默替换。

## 覆盖与验收分开

- 欧联、欧协：仅原生 `league-phase`。各有真实拟合的 Current 常量 Poisson 与 Test 球队攻防 Poisson；新配方不是旧 Champion。来源与历史诊断见 `europe-research-pairs-20261117.md`。
- 欧国联：按 A/B/C/D 各自 league-phase，接入修复后固定配方 Current/Test，不使用未过门槛的 challenger。
- 日联杯：仅原有 2026/27 八强首、次回合研究机制；次回合必须有经核验首回合上下文。没有当前可分析赛事时不得重发旧赛事。
- 世界杯：仅已核验小组赛研究双轨，淘汰阶段样本不足仍拒绝；芬超已按用户指令移出新分析范围，不再补数或建模。

赛事名称列入 20 项范围、已有模型工件、成功加载、真实赛前运行、未来效果验收是五种不同状态。阶段子集不等于覆盖全赛事。用户于 2026-11-17 明确移除芬超，历史记录保留。范围审计脚本只报告注册与哈希，不宣称执行过每项真实推理。

## 使用

先根据证据归档恢复真实资产并核对哈希，再运行：

```sh
PYTHONPATH=runtime python runtime/research_pair_service.py \
  --fixture verified-fixture.json --active-registry active-model.json \
  --research-registry research-registry.json --out new-diagnostic.json
```

此命令仅产生明确标为 `UNPUBLISHED_DIAGNOSTIC` 的计算结果，不是已发布赛前预测。正式交付仍需真实资料核验、独立综合比较及首次赛前冻结；不能在赛后倒签。数据缺失、模型失败、未知球队或阶段没有适配时明确报错。

`audit_research_pair_registry.py` 可列出 20 项的注册及依赖状态；其 `NOT_EXECUTED_BY_INVENTORY` 不得解释为通过真实推理。

## 数值和安全边界

当前/Test、研究候选、综合判断保持独立。输出比分众数是统计参考，不是自动完成综合唯一比分和 TOP3。实际大小球需要真实同机构、同盘线、来源报价时间；无报价不生成盘口。历史留出诊断缺 first-known 认证，不能称严格 as-of 或新未来实绩。

不更改模型晋级门槛，不购买数据，不启用新后台预测或自动换权重。新版本必须通过真实依赖加载、来源与时点、角色/阶段/球队拒绝测试、既有冻结矩阵一致性及适当完整回归后再交付。

## 本批实际结果

世界杯仅小组赛双轨完成：144 份真实合格比赛，124 拟合、20 日期留出后全量重拟合。留出统计比分两轨均 2/20，胜平负为 6/20 与 7/20；未证明改善。淘汰阶段仍因样本不足阻断。

芬超已取消：旧库 251 场没有可信阶段标签，ESPN 2025/2026 响应为空；补查找到部分公开阶段证据，但不足以核验完整训练集的阶段、球队身份与 90 分钟结果。历史记录保留，不再补数或训练，不依据日期猜常规/争冠/保级。

因此本批完成五项限定阶段研究双轨适配，20 项赛事名称各有对应活动或研究双轨入口，但并非全阶段、全数据条件下均可预测。原 15 项注册路线的工程加载复核中，12 项通过合成双矩阵测试；J1/K1/澳超缺可复用 fixture 的该审计未执行，不能以哈希完整代替本次运行通过。亚冠精英缺失的四个依赖文件已按历史归档逐件哈希恢复后加载通过。所有这些测试不发预测、不写冻结。
