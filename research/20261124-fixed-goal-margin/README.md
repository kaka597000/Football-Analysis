## 改动和约束

固定每场原矩阵里**每一个主队进球减客队进球的分差概率**。例如主胜一球原有的总概率完整保留，只校准 1–0、2–1、3–2 等在这条对角线上的相对概率。对任意净胜差，给“较少一方恰好进一球”的那一格乘同一个赔率比，然后在该对角线内部重新归一。两个进球数相同的情形也单独按净胜差零处理。

以 `p_d` 表示原矩阵在给定分差 `d` 时该格的概率，归一分母为 `1 + (exp(beta) - 1) * p_d`。其余各格之间的相对概率保持原值，原本为零的格子继续为零。由此完整保留胜平负和全部亚洲让球盘口的结算概率。单队进球分布、双方进球、总球和大小球概率可改变，需要独立计分。六联赛共用一个受约束的拟合系数，`beta = 0.1706930`，对应倍率 **1.18613**。

旧版 Dixon–Coles 调整四个低比分格，既有三臂试验使用主客零球及总球尾部，R7 先给总球概率再做主客分配，旧净胜差校准可调整让球分布。这里在同一净胜差内同时比较零封取胜、双方进球的一球差和更高比分的同差结果。原测试的赛前胜平负来自整张矩阵，两个模型各中 292 场。另按首选比分自身所含胜平负计算，错向 340 → 358 场。这两项口径各有含义。[研究协议](protocol.json) · [固定净胜差实现](recipe.py)

## 复现

使用 Python 3.12、仓库 requirements-integration.txt，以及 Data 仓固定提交内的现有归档。在本源码根目录执行。READER 是源码 #73 精确提交 `1788f1b14f5d8ed7e336e65bc3177cf4f3290415` 的干净签出，仅复用赛事身份、历史时间筛选、赛果和具名盘口读取。DATA 指向本地 Data 仓，OUT 指向一个新目录。

~~~sh
export PYTHONPATH=runtime OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1
S=research/20261124-fixed-goal-margin
PIN=a6d45024cf6cf622f05e4b378ab53cfe2d6ae329
mkdir -p "$OUT"
git -C "$DATA" show "$PIN:workspace-updates/20261123-kpi-optimization/source-assets.tar.gz" > "$OUT/season.tgz"
git -C "$DATA" show "$PIN:workspace-updates/20261123-prematch-literature/first-issues.tar.gz" > "$OUT/r7.tgz"
python "$READER/research/20261124-prior-shot-drought/history.py" train --archive "$OUT/season.tgz" --r7 "$OUT/r7.tgz" --out "$OUT/train.jsonl"
python "$S/study.py" fit --train "$OUT/train.jsonl" --out "$OUT/fit.json"
cmp "$OUT/fit.json" "$S/fit.json"
python "$S/inputs.py" inputs --reader "$READER" --archive "$OUT/season.tgz" --r7 "$OUT/r7.tgz" --out "$OUT/inputs.jsonl"
python "$S/study.py" seal --panel january --inputs "$OUT/inputs.jsonl" --fit "$OUT/fit.json" --out "$OUT/sealed"
cmp "$OUT/sealed/lock.json" "$S/locks/january.json"
python "$S/inputs.py" labels --reader "$READER" --archive "$OUT/season.tgz" --r7 "$OUT/r7.tgz" --lock "$S/locks/january.json" --sealed "$OUT/sealed/forecasts.jsonl" --out "$OUT/labels.jsonl"
python "$S/grade.py" --panel january --inputs "$OUT/inputs.jsonl" --fit "$OUT/fit.json" --forecasts "$OUT/sealed/forecasts.jsonl" --lock "$S/locks/january.json" --labels "$OUT/labels.jsonl" --out "$OUT/results.json"
cmp "$OUT/results.json" "$S/results/january.json"
python -m unittest discover -s "$S" -p 'test_*.py' -v
python scripts/run_tests.py --layer integration
~~~
