## 已修复

1. **冻结时点**：在取得锁并校验历史链后重新取当前时间；在序列化、fsync后落盘前再次检查赛前时点。等待或写文件跨过开球时间时拒绝新赛前冻结，并清理临时文件；相同幂等请求在赛后仍能恢复原冻结，不倒填新记录。
2. **融合输入**：拒绝已声明拒绝/不可用状态的专家，以及非零或非法overflow、错误比分语义/矩阵轴、晚于输入截止的工件时点。缺少历史可选声明的兼容行为保持，不能借此宣称完整认证。
3. **融合计算**：矩形矩阵在大小球结算输入处补零为方阵，输出融合矩阵保持原shape/概率；统计众数相似性从实际矩阵计算，避免旧primary标签误导。仍为未训练等权参考，未改变权重。
4. **盘口证据**：同机构、同盘线、同一实际时刻的不同报价，整组暂停比较并显式统计冲突；输入顺序不再决定首末报价。相同报价的重复快照保持可用。不同UTC偏移表示的同一时刻也会识别冲突。
5. **恢复及交付**：报告路径与恢复日志重名时提前拒绝；文件原子写入后同步目录；恢复时核验请求哈希与原冻结凭证、内容、身份、阶段和目录。显式模型输入的赛事ID、开球/截止时间必须匹配外层fixture，允许等价时区表示。冻结与交付使用日志的深拷贝快照。
