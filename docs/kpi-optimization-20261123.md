## 运行入口

- 默认双模型入口附加独立盘口基线、严格全赢选边参照和实际 Test 近况输入诊断。盘口基线核验同一事件、同一次采集、同一家机构、带来源报价时点的两类市场。对比分分布的计算只使用盘口与泊松结构。
- `scripts/train_kpi_candidate.py` 分别拟合近期进失球和真实xG的进球率、盘口比分分布校准。训练使用目标日期前的比赛信息，按赛季固定切分。
- `scripts/forecast_kpi_candidate.py` 运行独立候选和盘口对照，并从同一赛前输入冻结两个首版。缺盘口时可记录合格近期数据的独立比分与胜平负预测，大小球记录缺项。
- `runtime/research_program/kpi_validation.py review` 校验首版冻结与终场证据，计算四指标、逐场净增、覆盖、真实盘口五类结算。组别中有待完赛样本时继续列出。

```bash
python scripts/train_kpi_candidate.py FIXTURES.jsonl --protocol PROTOCOL.json --out TRAINING
python scripts/forecast_kpi_candidate.py --fixtures FUTURE.json --artifact ARTIFACT.json --out ISSUED
python runtime/research_program/kpi_validation.py review --plan PLAN.json --captures CAPTURE1.json CAPTURE2.json --results RESULTS.json --evidence-root EVIDENCE --out REVIEW.json
```

历史输入来自数据仓库本批归档，字段和来源有哈希。比赛概率证据通过 SHA-256 绑定到预测首版，复盘读取实际终场来源和真实盘线。

## 样本与决定

五大联赛2019/20至2023/24拟合8,955场，7,222场连接真实历史 Understat xG。2024/25选型1,752场，2025/26作为此前已经分析过的复核赛季。2026/27截至11月8日500场用于冻结选型后的后续日期评价。历史收盘代理缺少当时的来源发布时间，大小球样本均为有来源价格的2.5球线。另复核80场已有真实盘口来源时点的比赛，含整数、半球与四分之一球盘口。该批赛果在本轮研究开始前已经复盘。

先在新入口做独立赛前研究。第一轮真实赛前三场提取双方近六场xG，盘口报价来源时点缺失，大小球及盘口对照记缺项。四项目标待实战验收。固定高比分备选经1,752场复算，三选从540降到522，保留为研究。默认使用概率排序。真实前向预测、诊断和复盘可各自查到引用。
